# Contributing to Oozy Linux

**Thanks for helping the goo evolve.**

Oozy is built by people who want to make Linux easier to enter while still teaching users how it works.

You don't need to be an Arch expert to contribute.

## What You Can Contribute

- 🐧 Linux / Arch development
- 💻 Installer development
- 🎨 UI/UX and branding
- 📚 Documentation
- 🧪 Testing
- 🛠️ System configuration
- 🌐 Website development
- 💡 Ideas, suggestions, and feedback

## Getting Started

1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes.
4. Test them.
5. Commit your changes.
6. Open a pull request.

For larger changes, open an issue first so we can discuss the idea before you spend time building it.

## Issues

Issues may use labels such as:

- "good first issue" - Good for newcomers
- "help wanted" - Extra help is needed
- "documentation" - Documentation-related
- "testing" - Needs testing
- "installer" - Related to the installer
- "packaging" - Related to packages
- "website" - Related to the website
- "design" - UI, UX, or branding

## Pull Requests

Keep pull requests focused and explain:

- What you changed
- Why you changed it
- How you tested it

Small, focused pull requests are easier to review and merge.

Code and Documentation

Keep things simple, readable, and maintainable.

Don't add complexity just because you can.

Documentation should be understandable to someone who is still learning Linux.
