# Oozy Linux Roadmap

**Goal:** Ship **Oozy 1 mL** — the first bootable drop.

## Phase 1 — Foundation (Current)

- [x] Project structure
- [x] Basic archiso profile skeleton
- [x] KDE Plasma chosen as default Desktop Environment
- [x] Calamares chosen as installer
- [ ] Complete and test archiso profile (packages, configs, branding)
- [ ] Fully working Calamares configuration (branding + modules)
- [ ] Basic live environment (KDE Plasma session)
- [ ] First successful ISO build

## Phase 2 — Usable Prototype

- [ ] Polished Calamares installer experience
- [ ] Sensible default KDE Plasma look & feel (Oozy branding)
- [ ] Welcome / first-run application (introduce the Goo philosophy)
- [ ] Basic system tools and recovery helpers
- [ ] AUR helper pre-configured (yay or paru)
- [ ] Documentation for building the ISO

## Phase 3 — Oozy 1 mL Release

- [ ] Thorough testing (VMs + real hardware)
- [ ] Website / download page
- [ ] Official announcement
- [ ] Community channels

## Later (Post 1 mL)

- Learning system (progressive tips, guided challenges)
- Better recovery tools
- Optional desktop environments / spins
- Out-of-box Flatpak + AppImage support improvements
- Accessibility focus
