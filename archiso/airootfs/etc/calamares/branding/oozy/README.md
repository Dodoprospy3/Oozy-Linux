# Oozy Calamares Branding

Place the following files in this directory:

- `logo.png` — main logo (used in the installer sidebar and welcome)
- Optional: additional slides / images referenced by `show.qml`

Recommended size for `logo.png`: 256×256 or 512×512, transparent background preferred.

The current `branding.desc` and `show.qml` already reference `logo.png`.
